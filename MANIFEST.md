# Scaffold contents

- `AGENTS.md` — master workflow instructions; separates BUILD / LEARNING / INTERVIEW modes.
- `README-CODEX.md` — exact prompts to start and resume each mode.
- `docs/TASK_SPEC.md` — concise working copy of the assignment.
- `docs/PROJECT_RULES.md` — fixed stack, architecture and behavior decisions.
- `docs/GIT_RULES.md` — autonomous Git initialization, commit conventions, branch naming and GitHub publication rules.
- `docs/BUILD_PLAN.md` — fast implementation batches, no teaching in parallel.
- `docs/STATE.md` — persistent build state across chats.
- `docs/LEARNING_PLAN.md` — post-build curriculum based on the finished repository.
- `docs/LEARNING_STATE.md` — persistent learning state across chats.
- `docs/INTERVIEW_MODE.md` — defense and no-assistant change practice.
